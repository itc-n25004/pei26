# 演算子

## 1. 算術演算子 (Arithmetic)

| 演算子 | 名称・意味 | コード例 | 結果 | 備考 |
| :---: | :--- | :--- | :---: | :--- |
| `+` | 加算 | `5 + 2` | `7` | 文字列・リスト等の**連結**にも使用 |
| `-` | 減算 | `5 - 2` | `3` | |
| `*` | 乗算 | `5 * 2` | `10` | シーケンスの**反復**にも使用 |
| `/` | 除算 | `5 / 2` | `2.5` | **結果は常に `float` 型** |
| `//` | 切り捨て除算（床除算） | `5 // 2` | `2` | 負の無限大方向へ切り捨て（`-5 // 2 == -3`） |
| `%` | 剰余（余り） | `5 % 2` | `1` | |
| `**` | べき乗（累乗） | `5 ** 2` | `25` | `pow(5, 2)` と等価 |
| `@` | 行列乗算 | `A @ B` | 行列積 | Python 3.5+（NumPy 等の行列演算で使用） |

---

## 2. 比較演算子 (Comparison)

2つの値を比較し、ブール値（`True` または `False`）を返します。

| 演算子 | 意味 | コード例 | 演算子 | 意味 | コード例 |
| :---: | :--- | :--- | :---: | :--- | :--- |
| `==` | 等しい（等値） | `a == b` | `>` | より大きい | `a > b` |
| `!=` | 等しくない | `a != b` | `<` | より小さい | `a < b` |
| `>=` | 以上 | `a >= b` | `<=` | 以下 | `a <= b` |

> 💡 **比較の連鎖（連鎖比較）:** Python では `0 <= x < 10` のように比較演算子を連続して記述できます（`0 <= x and x < 10` と等価）。

---

## 3. 論理演算子 / ブール演算 (Logical / Boolean)

| 演算子 | 名称・意味 | コード例 | 動作の特徴 |
| :---: | :--- | :--- | :--- |
| `and` | 論理積（かつ） | `A and B` | `A` が偽と評価されれば `A` を返し、真なら `B` を返す |
| `or` | 論理和（または） | `A or B` | `A` が真と評価されれば `A` を返し、偽なら `B` を返す |
| `not` | 論理否定（〜でない） | `not A` | 真偽値を反転し、常に `bool`（`True` / `False`）を返す |

> 💡 **短絡評価 (Short-circuit evaluation):** 左辺の評価だけで結果が確定した場合、右辺は評価されません。フォールバック値（デフォルト値）の設定（`name = input_name or "Guest"`）にもよく利用されます。

---

## 4. 所属検査・同一性比較演算子 (Membership & Identity)

| 分類 | 演算子 | 意味 | コード例 |
| :---: | :---: | :--- | :--- |
| **所属検査** | `in` | シーケンスや集合に要素が含まれるか判定 | `'a' in ['a', 'b']` |
| **所属検査** | `not in` | シーケンスや集合に要素が含まれないか判定 | `'z' not in 'apple'` |
| **同一性比較** | `is` | 同一のオブジェクトか判定（`id()` が一致） | `x is None` |
| **同一性比較** | `is not` | 異なるオブジェクトか判定（`id()` が不一致） | `x is not None` |

> ⚠️ **`==` と `is` の使い分け:**
> * **等値性（値の比較）**を調べる場合：`==` を使用（例: `a == [1, 2]`）
> * **同一性（オブジェクトの比較）**を調べる場合：`is` を使用（`None`、`True`、`False` などのシングルトン判定: `if data is None:`）

## 5. 代入・累算代入演算子 (Assignment)

| 種類 | 演算子一覧 | 使用例・等価表現 |
| :--- | :--- | :--- |
| **基本代入** | `=` | `x = 10` |
| **累算代入（算術演算）** | `+=`, `-=`, `*=`, `/=`, `//=`, `%=`, `**=`, `@=` | `x += 1` $\rightarrow$ `x = x + 1` |
| **累算代入（ビット演算）** | `&=`, `\|=`, `^=`, `>>=`, `<<=` | `x &= 1` $\rightarrow$ `x = x & 1` |
| **代入式（セイウチ演算子）** | `:=` *(Python 3.8+)* | `if (n := len(items)) > 0:`<br>（変数への代入と値の評価を式の中で同時に行う） |

---

## 6. ビット単位演算子 (Bitwise)

整数を2進数表現とみなし、ビット単位で演算します（例：`5` = `0b0101`, `3` = `0b0011`）。

| 演算子 | 名称 | 例 | 結果（2進数） | 結果（10進数） |
| :---: | :--- | :--- | :---: | :---: |
| `&` | ビット単位 AND（論理積） | `5 & 3` | `0b0001` | `1` |
| `\|` | ビット単位 OR（論理和） | `5 \| 3` | `0b0111` | `7` |
| `^` | ビット単位 XOR（排他的論理和） | `5 ^ 3` | `0b0110` | `6` |
| `~` | ビット反転（1の補数 / NOT） | `~5` | `-(5 + 1)` | `-6` |
| `<<` | 左ビットシフト | `5 << 1` | `0b1010` | `10` |
| `>>` | 右ビットシフト | `5 >> 1` | `0b0010` | `2` |

## 7. 演算子の優先順位（高い $\rightarrow$ 低い）

評価順序を明確にしたい場合や迷った場合は、**丸括弧 `()`** で囲むのが推奨されます。

| 順位 | カテゴリ | 演算子 |
| :---: | :--- | :--- |
| **1** | 丸括弧・コンテナ表示 | `(...)`, `[...]`, `{...}` |
| **2** | 属性参照・添字・スライス・関数呼び出し | `x.attr`, `x[i]`, `x[i:j]`, `f(...)` |
| **3** | べき乗 | `**` |
| **4** | 単項演算（正符号・負符号・ビット反転） | `+x`, `-x`, `~x` |
| **5** | 乗算・行列乗算・除算・切り捨て除算・剰余 | `*`, `@`, `/`, `//`, `%` |
| **6** | 加算・減算 | `+`, `-` |
| **7** | ビットシフト | `<<`, `>>` |
| **8** | ビット単位 AND | `&` |
| **9** | ビット単位 XOR | `^` |
| **10** | ビット単位 OR | `\|` |
| **11** | 比較・所属検査・同一性比較 | `==`, `!=`, `>`, `>=`, `<`, `<=`, `is`, `is not`, `in`, `not in` |
| **12** | 論理否定（ブール NOT） | `not` |
| **13** | 論理積（ブール AND） | `and` |
| **14** | 論理和（ブール OR） | `or` |
| **15** | 条件式（三項演算子） | `x if cond else y` |
| **16** | 代入式（セイウチ演算子） | `:=` |
