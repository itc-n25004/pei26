# Python 演算子

## 1. 算術演算子 (Arithmetic)

| 演算子 | 意味 | コード例 | 結果 | 備考 |
| :---: | :--- | :--- | :---: | :--- |
| `+` | 加算 | `5 + 2` | `7` | 文字列・リストの結合にも使用 |
| `-` | 減算 | `5 - 2` | `3` | |
| `*` | 乗算 | `5 * 2` | `10` | 文字列・リストの繰り返しにも使用 |
| `/` | 除算 | `5 / 2` | `2.5` | **結果は常に `float`** |
| `//` | 切り捨て除算 | `5 // 2` | `2` | 負の数は小さい方へ丸め（`-5 // 2 == -3`） |
| `%` | 剰余（余り） | `5 % 2` | `1` | |
| `**` | べき乗 | `5 ** 2` | `25` | `pow(5, 2)` と同等 |
| `@` | 行列乗算 | `A @ B` | 行列積 | Python 3.5+（NumPy などで使用） |

---

## 2. 比較演算子 (Comparison)

結果はすべて `True` または `False` を返します。

| 演算子 | 意味 | コード例 | 演算子 | 意味 | コード例 |
| :---: | :--- | :--- | :---: | :--- | :--- |
| `==` | 等しい | `a == b` | `>` | より大きい | `a > b` |
| `!=` | 等しくない | `a != b` | `<` | より小さい | `a < b` |
| `>=` | 以上 | `a >= b` | `<=` | 以下 | `a <= b` |

> 💡 **連鎖比較:** Python では `0 <= x < 10` のように比較演算子をつなげて書けます。

---

## 3. 論理演算子 (Logical)

| 演算子 | 意味 | コード例 | 動作の特徴 |
| :---: | :--- | :--- | :--- |
| `and` | 論理積（かつ） | `A and B` | `A` が偽なら `A` を返し、真なら `B` を返す |
| `or` | 論理和（または） | `A or B` | `A` が真なら `A` を返し、偽なら `B` を返す |
| `not` | 論理否定（〜でない） | `not A` | 常に `bool`（`True` / `False`）を返す |

> 💡 **短絡評価 (Short-circuit):** 左辺だけで結果が確定した場合、右辺は評価されません。デフォルト値の設定（`name = input_name or "Guest"`）にもよく使われます。

---

## 4. 帰属・同一性演算子 (Membership & Identity)

| 分類 | 演算子 | 意味 | コード例 |
| :---: | :---: | :--- | :--- |
| **帰属** | `in` | 要素が含まれる | `'a' in ['a', 'b']` |
| **帰属** | `not in` | 要素が含まれない | `'z' not in 'apple'` |
| **同一性** | `is` | 同一オブジェクト（メモリ参照が同じ） | `x is None` |
| **同一性** | `is not` | 異なるオブジェクト | `x is not None` |

> ⚠️ **`==` と `is` の使い分け:**
> * **値の等価性**を調べるなら `==`（例: `a == [1, 2]`）
> * **`None` との比較**やシングルトン判定には `is`（例: `if data is None:`）

## 5. 代入・累算代入演算子 (Assignment)

| 種類 | 演算子一覧 | 使用例・等価表現 |
| :--- | :--- | :--- |
| **基本代入** | `=` | `x = 10` |
| **算術累算** | `+=`, `-=`, `*=`, `/=`, `//=`, `%=`, `**=`, `@=` | `x += 1` $\rightarrow$ `x = x + 1` |
| **ビット累算** | `&=`, `\|=`, `^=`, `>>=`, `<<=` | `x &= 1` $\rightarrow$ `x = x & 1` |
| **セイウチ演算子** | `:=` *(Python 3.8+)* | `if (n := len(items)) > 0:`<br>（代入と値の評価を同時に実行） |

---

## 6. ビット演算子 (Bitwise)

整数を2進数としてビット単位で操作します（例：`5` = `0b0101`, `3` = `0b0011`）。

| 演算子 | 名称 | 例 | 結果（2進数） | 結果（10進数） |
| :---: | :--- | :--- | :---: | :---: |
| `&` | ビット AND | `5 & 3` | `0b0001` | `1` |
| `\|` | ビット OR | `5 \| 3` | `0b0111` | `7` |
| `^` | ビット XOR | `5 ^ 3` | `0b0110` | `6` |
| `~` | ビット反転 (NOT) | `~5` | `-(5 + 1)` | `-6` |
| `<<` | 左シフト | `5 << 1` | `0b1010` | `10` |
| `>>` | 右シフト | `5 >> 1` | `0b0010` | `2` |

---

## 7. 演算子の優先順位（高い $\rightarrow$ 低い）

迷ったときは**丸括弧 `()`** で明示するのがベストプラクティスです。

| 順位 | カテゴリ | 演算子 |
| :---: | :--- | :--- |
| **1** | 括弧・コンテナ | `(...)`, `[...]`, `{...}` |
| **2** | 属性・添字・関数呼出 | `x.attr`, `x[i]`, `f(...)` |
| **3** | べき乗 | `**` |
| **4** | 単項演算 | `+x`, `-x`, `~x` |
| **5** | 乗除・剰余・行列積 | `*`, `@`, `/`, `//`, `%` |
| **6** | 加減 | `+`, `-` |
| **7** | ビットシフト | `<<`, `>>` |
| **8** | ビット AND | `&` |
| **9** | ビット XOR | `^` |
| **10** | ビット OR | `\|` |
| **11** | 比較・同一性・帰属 | `==`, `!=`, `>`, `>=`, `<`, `<=`, `is`, `is not`, `in`, `not in` |
| **12** | 論理 NOT | `not` |
| **13** | 論理 AND | `and` |
| **14** | 論理 OR | `or` |
| **15** | 条件式（三項演算子） | `x if cond else y` |
| **16** | セイウチ演算子 | `:=` |
